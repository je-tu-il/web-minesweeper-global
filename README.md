## ✨ Fonctionnalités Clés

- 🌍 **Multijoueur & Synchronisation en Temps Réel** : Les actions, découvertes de cases et drapeaux sont reflétés instantanément entre joueurs grâce à Firebase.
- 🏆 **Classement Mondial & Statistiques** : Suivi des records de vitesse, taux de réussite et historique des victoires.
- 📱 **Ergonomie Mobile & Tactile** :
  - Clic / Tap simple pour révéler une case.
  - Pression longue ou bouton dédié pour poser un drapeau.
  - Zoom et déplacement fluide sur les grandes grilles.
- 🎚️ **Plusieurs Niveaux de Difficulté** : Débutant, Intermédiaire, Expert ou grille sur-mesure.
- 🎨 **Interface Moderne & Soignée** : Composants Radix UI, animations fluides et thème sombre immersif.

## 🛠️ Lancement pour Développeurs (Code Source)

### Prérequis
- [Node.js](https://nodejs.org/) (version 18 ou supérieure)
- npm ou bun

### Installation
```bash
git clone https://github.com/je-tu-il/web-minesweeper-global.git
cd web-minesweeper-global
npm install
```

### Lancement du serveur local
```bash
npm run dev
```
Rendez-vous sur `http://localhost:5173/`.

### Lancer les tests unitaires
```bash
npm test
```

### Build de Production
```bash
npm run build
```
